# LeLamp Agent 对比结果

测试日期：2026-09-15。两套 Agent 使用相同 Qwen、人格文档和 23 个高层 Tool，在 Pi5 上依次运行，Control API 为不接触硬件的记录服务。每项三次，共 66 次。

| 指标 | Pi Agent Core | OpenClaw |
|---|---:|---:|
| 工具序列、参数与输出检查通过 | 59/66（89.4%） | 61/66（92.4%） |
| HTTP/运行错误 | 0 | 0 |
| 总延迟 p50 | 1.99 秒 | 3.26 秒 |
| 总延迟 p95 | 2.96 秒 | 5.78 秒 |
| Tool 返回后等待 p50 | 0.92 秒 | 1.29 秒 |
| 空闲 RSS | 约 104 MB | 约 388～440 MB |

Pi 明显更快、更省内存，动作、转向、办公照明、Timer、Alarm 和条件判断主流程均已跑通，但仍偶发只回答文字而未调用要求的 Tool。OpenClaw 整体工具遵循率稍高，针对性关键样例为 34/35，因此当前继续作为默认后端。

OpenClaw 也并非完全稳定：全量测试中出现过一次重复创建 Timer，以及少量漏掉情绪动作或追加多余情绪动作。Pi 保留为已部署候选，后续更换模型或继续收紧 Tool 策略后可用同一脚本复测。

默认后端的 Pi5 实机冒烟测试已通过：点头一次、进入/调暗/退出办公照明、左右转与回正、3 秒 Timer 到期后点头、天气和新闻搜索、Alarm 创建后取消、告别播报后机械休眠。日志确认 Timer 动作仅执行一次，测试 Alarm 已处于 `cancelled` 状态。

原始结果：`pi-ab-final.json`、`openclaw-ab-final.json`。

补充测试：官方 DeepSeek API 的 `deepseek-flash`（对应 DeepSeek-V4.1-Flash）在同一套 Pi Agent 66 个用例中取得 66/66，0 错误；p50 总延迟 1.75 秒，p95 2.34 秒，Tool 返回后等待 p50 0.81 秒。相比 Pi+Qwen 的 59/66、p50 1.99 秒、p95 2.96 秒，工具正确率和延迟均更好。测试使用假 Control API，未驱动真实硬件。
